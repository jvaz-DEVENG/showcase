APNG é PNG animado: guarda o brilho gradual e a transparência de verdade. Abre animado em qualquer navegador. O app Fotos do Windows mostra só o 1º quadro — arraste o arquivo para o Chrome para ver rodando.

GIF só aceita 256 cores e transparência de 1 bit — ou o pixel é opaco, ou é invisível. Por isso o brilho gradual só sobrevive num GIF com fundo sólido. Quer a animação sem fundo? Use o APNG acima.
